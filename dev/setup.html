    The Discord bot

    You need a bot of your own from the Discord developer portal:

    1. New Application → name it what people will see.
    2. Bot tab → Reset Token → copy the token (it is shown once).
    3. Bot tab → Privileged Gateway Intents → turn on Message Content Intent. Without it the bot hears nothing.
    ▶ Invite the bot waiting for the bot to appear in a server
    No server yet? Make one first →
    1. Open Discord and click the + at the bottom of the server list on the left.
    2. Create My Own → For me and my friends → give it a name → Create. It comes with a #general text channel and a General voice channel, which is where the voice bot joins by default.
    3. Come back here and click Invite the bot above; pick the new server in Discord's dialog.

    Discord does not let bots create servers, so this part is yours; everything after it is automatic.

    Who owns it

    Only these people can give the bot new tools, a shell and installs. Everyone else can talk to it and use what exists.

      The brain

      At least one of these. The bot answers with the first one you give (Claude preferred); an owner can switch later in chat or here. The tool builder (the forge) uses Claude when it has a key, so Anthropic is the one to have if you can.

      Voice (optional)

      With an ElevenLabs key the bot hears and speaks through their service. Without one it uses local speech engines, which work fine and cost nothing.

      It leaves when the channel empties or when someone says bye.

      Tool kit

      The bot's tools live in a folder named after this household. A new kit starts with nine basic tools and grows as people ask for things.

      The kit becomes a small git repo either way, so every tool the bot builds is a commit. With a URL here it also has somewhere to push; run git push -u origin main in the kit folder when you want it backed up.

      The vault

      Every key the bot uses, Discord, Anthropic, ElevenLabs and whatever its tools need later, goes into one encrypted file on this PC. Its passphrase is the one thing to keep safe: file + passphrase = a complete backup. You can change any key later from the console without touching Discord or the terminal.

      A configuration already exists on this PC

      Saving replaces the bot's token, keys and settings with what is on this page. The current files are backed up first as .env.bak-<time>, and the vault key and internal token are kept, so the secrets the bot's tools already use keep working. If you only wanted a look, use abort.

      Unlock the console

      This page is only reachable on the PC that runs the bot. It opens with the vault passphrase chosen at setup (the four words). Nothing here is sent anywhere.
