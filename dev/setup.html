bot-lab setup a Discord bot that builds its own tools

Everything you enter stays on this PC, in two small config files. Keys are only used to check they work.

1. The Discord bot

You need a bot of your own from the Discord developer portal:

  1. New Application → name it what people will see.
  2. Bot tab → Reset Token → copy the token (it is shown once).
  3. Bot tab → Privileged Gateway Intents → turn on Message Content Intent. Without it the bot hears nothing.

2. Who owns it

Only these people can give the bot new tools, a shell and installs. Everyone else can talk to it and use what exists. Your ID: Discord Settings → Advanced → Developer Mode, then right-click your name → Copy User ID.

3. The model

An API key from console.anthropic.com. The bot, and the tool builder, run on it.

4. Voice (optional)

With an ElevenLabs key the bot hears and speaks through their service. Without one it uses local speech engines, which work fine and cost nothing.

It leaves when the channel empties or when someone says bye.

5. Tool kit

The bot's tools live in a folder named after this household, so several households can share this repo. A new kit starts with eight basic tools and grows.

The kit becomes a small git repo either way, so every tool the bot builds is a commit. With a URL here it also has somewhere to push; run git push -u origin main in the kit folder when you want it backed up.
